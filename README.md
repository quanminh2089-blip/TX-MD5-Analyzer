# MinhQuan v0.8 — kiểm thử menu nổi trong game thật

Dựa trên mã nguồn MinhQuan v0.7. Đăng nhập bằng key/tài khoản thử nghiệm như bản cũ. Trong màn hình Matrix, bấm **BẬT / TẮT MENU NỔI TRÊN GAME**, cấp quyền **Hiển thị trên ứng dụng khác**, trở lại app và bấm nút lần nữa. Sau đó mở Liên Quân để kiểm tra lớp phủ. Có thể kéo menu và nhấn ĐÓNG.

**Giới hạn:** Đây là phép thử lớp phủ trên game thật, **không phải ESP vị trí tướng ẩn**. Không đọc bộ nhớ, không hook IL2CPP, không lấy vị trí đối thủ. Hiển thị trạng thái chưa có dữ liệu một cách rõ ràng. Trên một số máy/game, lớp phủ có thể bị chặn.

## Build
Dùng GitHub Actions có sẵn trong `.github/workflows/android-build.yml`. Chưa xác minh build APK trong môi trường này.
